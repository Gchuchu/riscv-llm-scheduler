# 板卡选型

赛题中推荐的两款板卡，均使用 **SpacemiT K1**（1.6GHz）内核，均有较为丰富的开源资料。

## 对比

| 特性 | BananaPi BPI-F3 | Milk-V Jupiter |
|------|----------------|---------------|
| 主控芯片 | SpacemiT K1（1.6GHz） | SpacemiT K1（1.6GHz） |
| RAM | 8GB | 8GB / 16GB |
| RVV 版本 | 1.0 | 1.0 |
| VLEN | 256 | 256 |
| 价格 | 约 ¥400+ | 约 ¥400+ |
| 开源资料 | [docs.banana-pi.org](https://docs.banana-pi.org/zh/BPI-F3/BananaPi_BPI-F3) | [milkv.io](https://milkv.io/zh/docs/jupiter/overview) |
| 散热 | 需额外购入散热器防止降频 | 自带散热方案 |

## 关键需求

赛题要求：
> 使用不超过 3B 参数量的量化模型（如 Llama-3.2-1B/3B Q4_K_M），在 2、4、8 并发请求场景下测试

这对 RAM 要求较大，建议板卡 **RAM ≥ 8GB**。

## 额外选项

- Milk-V Jupiter 系列有使用 **SpacemiT M1** 主控芯片的款型（1.8GHz，RVV 1.0，VLEN=256bit），配备 16GB RAM。
- BananaPi BPI-F3（8G）目前缺货。

## 推荐

**急用可以选择 Milk-V Jupiter K1 + 8GB**。
