# 性能评测方法与指标

## 评测指标

### 吞吐量（TPS）

每秒生成的 token 数。衡量推理服务的整体处理能力。

```
TPS = total_tokens / total_time_seconds
```

### 平均 TTFT（Average Time To First Token）

平均首 token 生成时间，单位毫秒。衡量用户感知的响应速度。

### P95 TTFT

95 分位首 token 生成时间，单位毫秒。衡量尾延迟，反映最差情况下的用户体验。

## 测试方法

### 评测基准

- 推理框架：llama.cpp server 模式
- 模型：Llama-3.2-1B/3B Q4_K_M 量化模型
- 并发场景：2、4、8 并发请求

### 基线配置

- 相同模型与量化版本
- 相同 `--threads` 参数
- 相同输入长度分布
- CPU 频率策略固定为 `performance` governor

### 数据采集

- 每组配置**至少重复 3 次**
- 报告的均值与标准差
- 对比优化前后的 TPS、平均 TTFT、P95 TTFT

### 环境区分

- **性能数据**：须来自真实 RVV 1.0 硬件
- **QEMU 数据**：仅作功能验证或补充分析，与真实硬件数据分开呈现
